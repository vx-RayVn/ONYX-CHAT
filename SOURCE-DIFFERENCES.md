# Public source snapshot

This snapshot preserves the browser, website, Windows and backend implementation but deliberately excludes private deployment material:

- No old Git history, private author addresses, operational handoffs, internal status reports, mail/payment evidence, local tools, provider settings, environment values, operator-address file, user content, archives or compiled installers.
- Production project/account identifiers in the exported text are replaced with deployment placeholders. The historical private migration is unchanged in the private project; only its public copy has a neutral comment.
- The proprietary `@livekit/krisp-noise-filter` dependency and runtime are not distributed. An explicit open fallback adapter leaves the browser's ordinary audio processing in place and never claims Krisp is active.
- Public installer links are unset until a fork builds its own release. Generated website assets are rebuilt from source; obsolete generated copies and screenshot media are omitted.
- The upstream founder avatar is replaced with an original generic SVG in this copy. Reserved upstream logos are identified in TRADEMARKS.md and must be replaced by forks.
- The public README/setup/contribution/security documents replace internal project notes. Backend credentials and local commerce-policy files are absent; closed defaults are regenerated by the build scripts.

These changes affect the isolated public copy. They do not replace the official production configuration, stored contracts, deployed migrations, Windows installer or customer data.
