# Security policy

Please report vulnerabilities privately to **support@onyxchat.site**, with subject `Security report`.

Include the affected version, a clear description, minimal reproduction steps and expected impact. Use synthetic data. Do not include passwords, private keys, customer messages or other people's personal information. Do not publish exploit details before a fix can be coordinated.

Do not access other accounts, send unsolicited messages, make real payments, disrupt the service or run high-volume tests. Stop when you have a minimal demonstration. Ask before any test that could affect real users.

Valid reports may be acknowledged with the Bug Hunter badge, with the reporter's consent. There is no promise of a monetary bounty or a fixed response time. The current 0.1 source line is the supported review target; this is not a security certification.
